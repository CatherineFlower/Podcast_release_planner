# Система планирования выпусков подкаста

Консольное приложение для планирования выпусков подкаста.

## Возможности
- добавление и просмотр выпусков;
- поиск по названию и теме;
- изменение статуса и удаление;
- фильтрация и сортировка;
- статистика;
- хранение данных в JSON.

## Структура
- `main.py` — меню приложения;
- `episodes.py` — работа с выпусками;
- `storage.py` — JSON;
- `utils.py` — безопасный ввод;
- `data/` — данные;
- `tests/` — pytest-тесты.

## Запуск
```
pip install -r requirements.txt 
python main.py
```

## Проверка
`pytest`

`flake8`
