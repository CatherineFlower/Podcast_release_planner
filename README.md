# Система планирования выпусков подкаста

## Назначение
Приложение предназначено для планирования и контроля подготовки выпусков подкаста.

## Целевая аудитория
Авторы подкастов и команды, занимающиеся подготовкой и публикацией выпусков.

## Предметная область
Предметная область проекта — планирование выпусков подкаста от выбора темы до публикации.

## Основные сущности
- Подкаст — проект, в рамках которого создаются выпуски.
- Выпуск — отдельный эпизод подкаста.
- Тема — содержание выпуска.
- Статус — текущее состояние подготовки выпуска.

## Основные функции
- определение текущего статуса выпуска;
- проверка готовности выпуска к публикации;
- определение количества дней до публикации.

## План развития
На следующих этапах планируется:
- расширение функциональности программы;
- подключение базы данных;
- разработка веб-приложения на Django;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
