# Система планирования выпуска подкастов

Консольное приложение для планирования подкастов, тем и выпусков.

## Назначение

Приложение позволяет хранить подкасты, темы и выпуски, планировать даты
публикации, изменять статусы выпусков, выполнять поиск, фильтрацию,
сортировку и получать статистику.

## Целевая аудитория

Авторы, редакторы и небольшие команды, занимающиеся подготовкой подкастов.

## Предметная область

Планирование выпуска подкастов от идеи и выбора темы до готовности
и публикации выпуска.

## Основные сущности

1. **Podcast (Подкаст)** — проект, в рамках которого создаются выпуски.
2. **Episode (Выпуск)** — отдельный эпизод подкаста.
3. **Topic (Тема)** — тематика конкретного выпуска.
4. **Status (Статус)** — этап подготовки выпуска:
   `idea`, `planned`, `recording`, `ready`, `published`.

На ПР2 классы не используются. Сущности представлены словарями,
списками, множествами и другими структурами данных Python.

## Возможности

- просмотр, добавление и поиск подкастов;
- просмотр, добавление и поиск тем;
- просмотр и добавление выпусков;
- поиск выпусков по названию;
- изменение статуса;
- удаление выпуска;
- фильтрация по статусу;
- сортировка по дате публикации;
- статистика по статусам;
- сохранение данных в JSON;
- демонстрация интроспекции структуры данных.

### Назначение файлов

- `main.py` — точка запуска и консольное меню.
- `podcasts.py` — функции работы с сущностью Podcast.
- `episodes.py` — функции работы с сущностью Episode.
- `topics.py` — функции работы с сущностью Topic.
- `statuses.py` — справочник и функции сущности Status.
- `storage.py` — загрузка и сохранение JSON.
- `utils.py` — безопасный ввод и интроспекция.

- `tests/` — автоматизированные тесты pytest.
- `requirements.txt` — инструменты разработки.

## Инструменты разработки и зависимости

Основной код использует стандартную библиотеку Python.
Внешние зависимости нужны только для разработки.

### pytest

`pytest` — фреймворк автоматизированного тестирования.

Где используется:

```text
tests/
```

Запуск:

```bash
pytest
```

Тесты проверяют добавление, поиск, сортировку, фильтрацию,
изменение статуса и удаление данных.

### flake8

`flake8` — линтер Python-кода. Он проверяет соответствие PEP 8,
длину строк, неиспользуемые импорты и другие ошибки оформления.

Запуск:

```bash
flake8
```

Если команда ничего не выводит, замечаний нет.

### Форматирование

Отдельный внешний форматтер (`black`, `autopep8`, `ruff format`)
в проект не добавлен. Форматирование выполняется средствами PyCharm,
а результат проверяется линтером `flake8`.

### requirements.txt

Файл содержит инструменты, необходимые для тестирования и проверки кода:

```text
pytest>=8.0
flake8>=7.0
```

Установка:

```bash
pip install -r requirements.txt
```
